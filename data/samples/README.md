# Fichiers d'exemple

| Fichier | Origine | Contenu | Cas testé |
|---|---|---|---|
| `ventes_2025_2026.csv` | généré pour ce projet (fictif) | 1 500 commandes | INGEST |
| `ventes_quarantaine.csv` | généré pour ce projet (fictif) | commentaire en partie vide | QUARANTINE |
| `ventes_rejet.csv` | généré pour ce projet (fictif) | quantités négatives | REJECT |
| `rh_employes.csv` | généré pour ce projet (fictif) | 600 employés | données hors vente |
| `sales.csv` | Microsoft, [MicrosoftLearning/dp-data](https://github.com/MicrosoftLearning/dp-data) | 32 718 lignes Adventure Works | pas de colonne de montant, taxe |
| `orders.zip` | Microsoft, [MicrosoftLearning/dp-data](https://github.com/MicrosoftLearning/dp-data) | mêmes commandes, un fichier par année, sans en-tête | archive ZIP, fichiers sans en-tête |

Les fichiers générés ne contiennent aucune donnée réelle ; les personnes et
adresses e-mail d'Adventure Works sont fictives.
